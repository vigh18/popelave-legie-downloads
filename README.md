# Popelavé legie — stažení pro Android

Testovací APK najdete v [Releases](https://github.com/vigh18/popelave-legie-downloads/releases).

Podporuje Android 8 a novější, ARM 32/64 bit. Stáhněte `PopelaveLegie.apk`, otevřete soubor v telefonu a podle výzvy povolte instalaci z daného zdroje.

Hra potřebuje internet a používá veřejný backend. Při prvním spuštění potvrďte vytvoření vlastního účtu. Aktualizace instalujte přes stávající aplikaci bez odinstalace, abyste zachovali místní přístup k účtu.

Jde o interní testovací build podepsaný vývojovým klíčem. Sestavení a podpis byly ověřeny; běh na fyzickém Android telefonu zatím nebyl ověřen.

Tento repozitář obsahuje distribuční soubory, nikoli zdrojový kód.
